01

延续

现有页头的圆形「题」印升级为方印，保留老用户已经认识的字符与朱砂色。不是换品牌，是把品牌收得更端正。

02

场景

适合页头、Word 封面、公众号头图与线下物料；16px 标签页建议搭配 01 朱印，保证小尺寸仍然清楚。

03

边界

不添加星芒、渐变、机器人或节点网络。只用纸、墨、朱砂与宋体，让标识和界面保持同一种安静。

单色镂空版本 / MONO
去掉朱砂，只保留印与勾，可用于钢印、单色印刷与传真件。

HOW TO CHOOSE

如果只选一枚，怎么选。

07 做主标，01 做小尺寸伴侣，是这套方向里最稳的组合。其余方向按使用场景取用。

方向最适合注意
07 题印主标首选延续现有「题」印，辨识度最高；16px 建议搭配 01。
01 朱印小尺寸备选16px 最稳，适合 favicon、App icon 与浏览器标签页。
02 引文编辑气质最安静，适合出版、内容与公众号头图，识题性略弱。
03 双卷产品叙事直接对应题目版 + 答案版双 Word，适合导出场景。
06 折角审稿隐喻强调人工复核与批注，适合复核页与培训场景。
08 折页 D拉丁语境给 Doc2Exam 的独立字符号，适合 GitHub 与英文物料。
